# {{SITE}} navigation proposal: reading guide

This folder is the delivery package for the navigation menu of {{SITE_URL}}. It holds three files. This page says what each file is, in which order to read them, and what you must decide.

## The three files

| File | What it is | How to open |
|---|---|---|
| proposal.md | The proposal. Page one is a summary. Then one section per menu with the change, the reason, the data and the competitor practice. The last section lists the decisions that are yours. | any Markdown reader, or a text editor |
| mockup.html | A clickable mockup of the new menu. Hover a top-level item to open the desktop dropdown. In the phone frame, tap the menu icon, then tap an item. | double-click, no network needed |
| changes.csv | One row per menu item. The columns are the old place, the new place, the page, the product count, the traffic, the search volume, the change type and the reason. Use it for review and implementation. | Excel or Numbers |

## Reading order

1. Open mockup.html. Spend three minutes on each desktop dropdown and each mobile level.
2. Read the one-page summary in proposal.md.
3. If a change raises a question, open its section. Each section has a before-and-after tree and a five-column table.
4. Read the client decisions section.
5. Look up terms in appendix two.
