# {{SITE}} 导航栏优化方案：阅读指南

这个文件夹是 {{SITE_URL}} 导航栏优化方案的交付包，共三个文件。本页说明每个文件是什么、按什么顺序看、看完需要您决定什么。

## 三个文件

| 文件 | 是什么 | 怎么打开 |
|---|---|---|
| proposal.md | 方案书。第一页是摘要，后面按菜单逐节写怎么改、为什么、数据和竞对对照，最后是需要您决定的事、实施步骤和术语表 | 任何 Markdown 阅读器，或直接用文本编辑器 |
| mockup.html | 可点的新菜单示意。上半是桌面页头，鼠标移到一级项上展开大菜单；下半是手机框，点右上角菜单，再点一项展开 | 双击用浏览器打开，不需要联网 |
| changes.csv | 逐项追踪表，每行一个菜单项的原位置、新位置、网址、商品数、流量、搜索量、改动类型、理由 | Excel 或 Numbers |

## 建议的阅读顺序

1. 先打开 mockup.html，花三分钟把桌面每个下拉和手机每个一级点一遍。
2. 读 proposal.md 的“一页摘要”。
3. 对某个改法有疑问时翻对应章节，每节先是一棵“现状 → 改成”的树，再是一张五列表。
4. 读“需要客户决定的事项”。
5. 不懂的词查附二术语表。
